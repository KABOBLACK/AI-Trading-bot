# AI Trading Bot

An educational algorithmic trading system built with Python.

The goal of this project is to develop a complete trading system that can analyze market data, generate trading signals, manage risk, backtest strategies, and eventually support paper trading.

## Project Status

🚧 Version 1 — In Development

Current features:

- Moving-average trading strategy
- BUY / SELL / HOLD signals
- Basic backtesting
- Risk management
- Position sizing
- Paper-trading architecture
- Automated strategy testing
